# Git and GitHub Assignment

## Overview

This project demonstrates the basic Git and GitHub workflow,
including repository initialization, commits, pushing, and
sharing a public repository.

## Project Structure

```text
git-github-assignment/
├── scripts/
│   └── sample_data.py
├── README.md
└── .gitignore
```

## Requirements

- Python 3.8 or later
- Git

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the script:

```bash
python scripts/sample_data.py
```

The script generates `sample_data.csv` containing example
student records.

## Git Workflow

This project demonstrates:

- `git init` — initialize a local repository
- `git add` — stage changes
- `git commit` — save a version of the project
- `git push` — upload commits to GitHub
- `git pull` — retrieve remote changes

## Data Notice

All student records in this project are fictional examples
created for educational purposes.
